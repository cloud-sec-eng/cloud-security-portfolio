# Cloud Security Engineering Portfolio

Enterprise cloud security engineering portfolio featuring Azure, AWS, Terraform, DevSecOps, and infrastructure security.

## Portfolio Mission

This portfolio documents my progression in Cloud Security Engineering through a progressively expanding enterprise-style cloud lab.

The primary focus is Azure security architecture, followed by AWS security, infrastructure automation, DevSecOps, and container security.

Projects are designed to demonstrate practical engineering capabilities, including:

- Designing secure cloud infrastructure and network architectures
- Implementing identity, access control, and network segmentation
- Automating infrastructure with Terraform and scripting
- Monitoring security events and investigating misconfigurations
- Testing security controls and documenting validation evidence
- Troubleshooting failures and explaining technical design decisions

The portfolio distinguishes professional experience from independently completed lab projects. Projects are marked complete only after their functionality and security controls have been verified.
